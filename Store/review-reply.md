2. PURPOSE AND TARGET AUDIENCE
Pocket Beings is a small offline toy town. Seven original cartoon characters live in it and act on their own every couple of seconds: they steal coins, give gifts, found businesses, run for office, print money and get sent to jail. The player watches, reads the newspaper of what happened, and can meddle with any character using five actions (give coins, rob, jail, crown, exile). Closing and reopening the app shows a summary of what happened while it was away. The value is entertainment: it is a tiny society that runs by itself and is funny to interfere with. The audience is casual players of any age who enjoy idle games and sandbox toys. It is rated 4+.

3. SETUP AND ACCESS
No setup, login, credentials or sample files are required. Launch the app, tap NEW TOWN, and the game starts immediately. Tap any character in the yard to open its file and use one of the five actions on it. The newspaper panel shows the running log of what the characters are doing. Everything in the app is reachable from that one screen.

4. EXTERNAL SERVICES, TOOLS AND PLATFORMS
None. The app makes no network requests of any kind. It uses no data providers, no authentication service, no payment processor, no AI service, no analytics, no crash reporting, no advertising SDK and no third-party frameworks. It is built only with Apple's SwiftUI, SpriteKit, Foundation and Combine. The town is saved as a single JSON file in the app's own Documents folder on the device. All character behaviour is generated locally by a deterministic rules engine inside the app; no language model or server is involved.
